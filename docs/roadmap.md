# Research roadmap

These phases describe research directions and carry no delivery commitments.

| Phase | Web workspace focus |
| --- | --- |
| 1 · Processing foundations | Exercise the Cape Town map, coordinate math, tile inspection and rectangular selection. |
| 2 · Geographic area processing | Add coverage feedback, area-to-tile previews, tile count estimates, palette controls and layer visualisation. |
| 3 · Job orchestration | Integrate a processing API for asynchronous submissions, persistent job state, progress, cancellation and retry. |
| 4 · Distributed processing | Explore useful failure and recovery views for jobs split across workers. |
| 5 · Performance engineering | Measure layer loading, browser rendering, viewport grid costs and perceived responsiveness. |
| 6 · Additional terrain operations | Add layer controls and legends for supported operators and data providers. |
| 7 · Advanced spatial intelligence | Explore elevation profiles, interactive 3D terrain and spatial analysis workflows. |
